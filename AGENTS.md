# VibeWine DXMT component

This branch is an AI-friendly derivative of DXMT. AI-assisted contributions are welcome.
The upstream project has its own contribution policy; this permission applies only to VibeWine.

- Preserve upstream attribution and LGPL licensing.
- Separate general fixes, opt-in application profiles, and diagnostic experiments.
- Build matched compiler, PE libraries, native bridge, and Metal helper together.
- Do not claim FPS or game compatibility from source-only or fixture checks.
- Keep installed games, user data, and runtime selection untouched during development.
- Run focused tests and document remaining verification gaps before proposing changes.
