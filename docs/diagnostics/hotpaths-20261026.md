## General correctness

- Occupied `BindingSet` replacement now updates the new resource's hazard bit.
  Both hazard transitions, actual SRV/VB traits, boundary slots and COM ownership
  have old-fail/new-pass controls.
- Graphics PSO equality/hash now include the canonical stream-output layout.
  Different declarations/strides no longer alias one PSO; equivalent descriptors
  retain canonical identity and reuse. This is separate from ShaderVariant hashing.

- Resolve folding no longer moves a resolve backward across a live encoder.
  Null-only adjacency and already absorbed resolves remain eligible; other folds
  and dependency stops are preserved. The real access tracker supplies the
  regression dependencies; both bounded and unbounded old paths fail. This
  conservative guard can retain extra passes and needs performance comparison.

## What improved in metrics

Events 104–107 split cache-reader mutex waiting, AIR conversion, Metal
`newLibrary`, and `newFunction`, with exact task/operation/generation identities.
Existing cache-read event 93 keeps its post-lock semantics. The decoder rejects
impossible cache/fallback/exception chronology, cross-thread and stale identities;
missing stages remain unknown. These scopes measure elapsed steady-clock time,
not thread CPU, OS runqueue delay or a proven critical path. Stages from parallel
tasks must not be summed into one stall.

Before starting optional native observation, profile gates now skip feedback
QUERY/OPEN/POLL/STATUS/REGISTER and completed-buffer GPU timestamp property
reads for the compiler-only profile. Existing native owners still drain/CLOSE.
Actual operation counters and gate-removal controls check this distinction;
other legacy clock reads remain and whole-observer overhead is unmeasured.

The session parser now accepts coherent aggregates over five seconds through
four hours as **excluded coverage**, preserving watermarks and continuing with
subsequent valid records. Their duration/counts never inflate rate totals.
Malformed/overlapping/foreign records still fail or are explicitly discarded.
Details are bounded to 128 scalar records; original input remains retained.

## Full metrics means evidence across the chain

| Channel | Available / remaining acceptance |
| --- | --- |
| Game/API and waits | Existing API/task/queue probes plus new compiler stages; blocked vs runnable needs a bounded OS scheduler trace, not wall-minus-CPU inference |
| Encoding/submission/GPU | Existing queue identities and completed command-buffer GPU timing; overlapping command buffers are not frame GPU time |
| Actual presentation | Existing native callback path is separate from vendor aggregates; prove actual process birth, drawable/layer lifetime, configuration and losses before accepting a displayed-cadence number |
| Scene/configuration | Explicit menu/loading/gameplay observations and actual render/output dimensions; no automatic combat classification from FPS curves |
| Host pressure | Existing process/host sample consumer; swap/thermal/power must retain actual host/process scope and capability, unavailable is not zero |
| Observer health | Record slot/detail/native losses, sample latency, CPU and bytes; independent disabled/unarmed/light/detailed comparison remains required |

Use a bounded lightweight session plus a short, selected detailed attribution
window. The 131072-slot lifetime file is append-only: rearm does not reset it.
Even ignoring metadata/tail, ten minutes requires <=218.45 records/s. The current
full producer can exceed this substantially. Admission budget is a preflight,
not an automatic time limit. Calibrate actual rate and reject saturated or
all-skipped evidence; do not promise ten minutes of every per-frame event.
No new perpetual collector, privilege grant or screen-capture service is added.

## Remaining investigations, not claimed fixes

1. Initializer retry/publication: `dxmt_resource_initializer.cpp` allocation
   macros use `continue` inside `do/while(0)`, dropping the failed operation
   after flush. Reserve/fill/publish and bounded retry/terminal failure require
   a separate design; simply changing to an infinite loop is unsafe. Partial
   publication reaching native execution is not yet independently reproduced.
2. Redundant IA/shader/VB state setters: count exact-repeat incidence first;
   preserve pass reopen, DISCARD, ClearState and deferred restore.
3. GS/TS marshal and fence transport batching: preserve every declaration,
   stage, barrier and completion. Count 0/1/many distributions before changing
   singleton paths; reduced transport does not mean fewer GPU dependencies.
4. Group adjacent equal resource declarations only within interpreter
   boundaries; reject usage widening or ordering changes.
5. Semantic blend hashing: first measure equality/GetDesc1 collision cost;
   pointer/raw-padding hash cannot replace semantic equality.
6. Cache-reader concurrency and duplicate parsing: new attribution must show
   critical contention before adding per-key waiters/read connections. Removing
   the existing SQLite mutex is unsafe.
7. Depth/stencil initial uploads, contiguous staging rows and raster shadow are
   source-backed candidates, with workload frequency and native equivalence
   still unmeasured. MetalFX direct-to-drawable/MSAA changes require separate
   format, gamma, lifetime and presentation proof.
