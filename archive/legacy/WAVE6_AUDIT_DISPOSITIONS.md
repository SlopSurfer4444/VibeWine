# Wave6 audit dispositions

This table normalizes the prior architectural audit; the private browser transcript and owner diagnostics are excluded. Fixed means the named source defect was repaired and checked within the stated model. It does not imply the historical DS3 incidents share a cause or that all requested experiments passed.

|Finding / audit package|Disposition and evidence boundary|
|---|---|
|R1 / T1 capture finality|Fixed in V2: one generation/state/writer admission CAS, counted reservation/publication, bounded 250 ms drain, no forced counter repair. Stop timeout remains CLOSING; rearm refused. CREATE_NEW prevents same-session file truncation. Actual writer fork/barrier tests exercise admission, reservation and publication; structural completeness never means all GPU/API work completed.|
|R2 / A2 scheduler shutdown|Fixed predicate update under waiter mutex, notify/join outside mutex, closed submission gate. Deterministic lost-wakeup seam, idle/running/continuation/late-submit fixtures pass. Not established as DS3 cause.|
|R3 / A1 domain arguments|Fixed explicit discriminator, initialized argument chain and domain-only cache-key revision. Twelve argument-chain cases pass; real hull/domain Metal rendering remains unverified.|
|R4 / A3 statistics|Fixed synchronized updates and immutable completed snapshots, sample denominator/minima/counter arithmetic. Release statistics and unused HUD formatting compile out; debug container requires both CPU and encoding completion. These are not GPU completion statistics. ASan/UBSan arithmetic/concurrency and zero-allocation release fixtures pass. Debug overhead remains unmeasured.|
|R5 / F1 pending physical restore|Fixed restore obligation survives logical exit, original display name retained, explicit leave retries, failure HRESULT propagated. No per-Present retry. Terminal cleanup detaches member-backed HWND token and records failure; destructor has no durable external retry owner.|
|R6a / F2 ResizeTarget failure|Fixed mode-change HRESULT precedes descriptor commit; selected success values retained.|
|R6b / F2 Win32 mutation failure|Fixed checked monitor/rect/style/property/position operations, correct zero-plus-last-error handling, individual retry obligations, HWND token validation and partial cleanup. Final validate-to-mutate gap cannot be made atomic across multiple Win32 calls. Terminal RemoveProp refusal remains a reported failure.|
|R6c / F2 DEVMODE|Fixed zero initialization, dmSize and dmDriverExtra for current/registry restore queries. Display-name/enum failure is an error. Display name is not EDID identity across hotplug.|
|R7 / P1 DONOTFLUSH|Retained compatibility policy; flag clearing remains. Wait/flush/commit reason instrumentation distinguishes attempts from actual chunk publication. No broad flush removal or speed claim. Polling compatibility and measured optimization remain future work.|
|R8 move guard|Fixed ownership transfer with moved-from pointer cleared; chained/default moves yield exactly one unlock. No claim of a demonstrated existing cache race.|
|R8 / H1 HDR|Deferred fidelity track. SetHDRMetadata early S_OK and unreachable application logic remain unchanged. HDR capability, metadata validation and tone-map reference comparison are unverified.|
|T2 full API/lifecycle and identity|Whole Present/GetData/Map/Flush/resize/fullscreen CPU scopes, process-monotonic queue/swapchain birth serials, submission reasons and queue/swapchain/native-release phases included. Final DS3 exclusive refusal is inside the API timer. Unarmed helper has no timestamps/payloads; runtime overhead/drop-rate measurements remain pending. Legacy threshold-censored scopes remain censored.|
|F0 recovery fixture|Disposable real GPU smoke passed windowed and borderless readbacks, minimize/restore and WM_CLOSE. This does not prove recovery from dangerous exclusive modeset or WindowServer hangs.|
|F3 Metal view ownership|Deferred: overlapping swapchains on HWND, handle reuse and native view/layer lifetime need a native capability/ownership design. No speculative process-global map or upstream change admitted; no proven DS3 causal attribution.|
|N1 production identity|Deferred session/process/window router. Private fixture Parent/Target/Helper mapping is excluded; HWND-only AXIdentifier has reuse limits. Bundle/title alone cannot authenticate session identity.|
|N2 native AX|Preserve current startup/refcount, revision/generation/cookie, deadline/quarantine and cache-only getter guards. Five native source fixture cases / 56 assertions passed under ASan/UBSan. Shallow exact-target AX does not establish deep content traversal, Win32 actions/readback, real COM cancellation or CUA readiness. Native action success is queue admission; state/event readback remains required before consequential retry.|
|N3 CUA discovery/cancellation|Unresolved. Fixture supervisor duration and much later CUA return measure different boundaries; neither proves AX deadlock or Wine cleanup duration. Actual raw game remains absent from CUA inventory.|
|N4 Retina/input|Single DS3 session screen/controller accepted. Mixed DPI, monitor movement/primary change/hotplug, AX hit-test/click and negative-origin matrix remain future work. Mouse Z-order/coordinate leads are not confirmed new defects. Optional XInput stays unlinked/uninstalled/hardware-unverified.|
|D1 teardown/first fault|Phase timings added, but final-build normal game exit, process settlement and first caller stack/exception attribution remain unverified. AppKit Quit, in-game Exit and prefix-wide cleanup have different save/session semantics. Helper Quit is not session authenticated.|
|P2 allocation/cache/compiler|Deferred profiling. No broad tuning admitted; SQLite NOMUTEX alone does not establish a race.|
|P3 pacing/native presentation|Deferred native presentation feedback, pipeline/backpressure attribution, matched same-scene settings/cache comparison and input-latency evaluation. CPU cadence and GPU interval union are not displayed FPS or GPU utilization.|
|A0 / R0 integrated control|Exact final renderer identity and 69-TU build recorded; immediate playable screen goal accepted in one DS3 session. Native Wine implementation preserved. External donor dependencies and the management launcher remain separate; no full installed-runtime reproducibility claim.|
