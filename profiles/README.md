# Game profiles

Title-specific behavior belongs in an explicit executable/profile selection,
with enable/disable instructions and a test of the unaffected default path.
This directory is a contribution boundary, not a newly implemented loader.

The retained [DS3 classification](../current/README.md) records earlier display
mode caps and compatibility choices. Check the pinned component source before
claiming those choices are enabled in the new integrated build. Keep saves,
accounts, prefixes and machine paths out of public profiles.
